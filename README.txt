# MS DESIGN Studio & Printing Website

Files:
- index.html
- style.css
- script.js
- assets/ms-design-logo.jpg

Open `index.html` in a browser to preview.

The site uses the uploaded MS DESIGN logo and includes:
- Responsive navigation
- 6-slide hero slider
- Services
- Store/category filtering
- WhatsApp ordering
- Graphic/printing/sublimation service lists
- Photography section
- Gallery lightbox
- WhatsApp contact form
- Floating WhatsApp button

Note: Hero/gallery visuals use remote Unsplash image URLs. For a fully self-contained offline website, replace those URLs with your own local images.
